# 전격문고 FIGHTING CLIMAX PS Vita 한글패치

PS Vita 일본판 **전격문고 FIGHTING CLIMAX(電撃文庫 FIGHTING CLIMAX, PCSG00341)**용 비공식 한국어 패치입니다. 스토리 모드 대사, 승리 대사, 메뉴·시스템 메시지, 기술표, 칭호 등 게임 텍스트 파일 **295개**를 직접 한국어로 옮겼습니다. 실행 파일(`eboot.bin`) 안의 버튼 안내 문구 28개와 전투 중 서포트 캐릭터 말풍선 142개도 바꿨습니다. 게임 글꼴에는 한글 **1,027자**를 넣었습니다.

그림 글자도 한글로 다시 그렸습니다. 다음이 포함됩니다.
- 타이틀, 메인 메뉴, 캐릭터 선택 화면(세로 프로필·대사·이름, 작품명 한글 자막)
- 전투 HUD, 승리 화면, 갤러리·뮤직 목록, 부팅 경고문
- 스페셜 > 노벨 갤러리 19권 본문 **389쪽**(세로쓰기)

현재 배포판은 **v1.0.3 (2026-11-18)**입니다.

[패치 다운로드](https://github.com/snake759494/dengeki-bunko-fighting-climax-vita-korean-patch/releases/latest) · [기술 설명](docs/TECHNICAL.md) · [재빌드](docs/BUILD.md) · [용어집](docs/GLOSSARY.md) · [변경 기록](CHANGELOG.md) · [권리 안내](RIGHTS.md)

릴리즈 첨부 파일은 ZIP 하나입니다. 안에는 바뀐 게임 파일 **948개** 각각에 대응하는 xdelta가 게임 폴더와 같은 구조로 들어 있습니다. 저장소에는 제작 소스와 한국어 번역만 공개합니다. 다음 파일은 포함하지 않습니다.

- 원본·완성 게임 파일
- 추출한 게임 데이터·그림
- 일본어 원문
- 글꼴 파일
- 외부 실행 파일

GitHub가 자동으로 만드는 Source code ZIP/TAR는 저장소 소스를 압축한 것이며 게임 파일이 아닙니다.

## 게임 소개 및 대상 버전

『전격문고 FIGHTING CLIMAX』는 세가가 개발한 2D 대전 격투 게임입니다. 전격문고 라이트노벨 작품의 캐릭터들이 등장합니다. 2014년 아케이드판에 이어 PS3·PS Vita판이 일본에서 나왔습니다.

이 패치는 **PS Vita 일본판(PCSG00341)**을 PKGj·pkg2zip·Vita3K로 설치한 게임 폴더(`ux0:app/PCSG00341/`)에 적용합니다. 패키지 원본 그대로이며 업데이트 패치는 적용하지 않은 상태입니다. `eboot.bin`은 설치된 그대로(원본 MD5 `f78cd0224bda41cd86d76e735a2a8640`)여야 합니다. 원본 파일별 크기와 해시는 [release_manifest.json](release_manifest.json)에 있습니다.

## 패치 적용 방법

### 1. 받기

릴리즈에서 `Dengeki_Bunko_Fighting_Climax_Vita_KO_v1.0.3_xdelta.zip`을 받아 압축을 풉니다. 안에는 다음이 들어 있습니다.

- `적용하기.bat`: Windows용 적용 도구(Python 필요 없음)
- `list.txt`: 파일 목록과 원본·결과 MD5
- `xdelta3.exe`: xdelta 3.1.0([공식 프로젝트](https://github.com/jmacd/xdelta), Apache License 2.0)
- `patch/PCSG00341/`: 파일별 xdelta 948개. 예: `patch/PCSG00341/grpdat/Title/taitle_logo00.gxt.gz.xdelta`

### 2. 적용

**Windows(권장, Python 필요 없음)**

1. 설치된 원본 게임 폴더 `PCSG00341`을 통째로 압축을 푼 폴더에 복사합니다. `적용하기.bat` 옆에 `PCSG00341\eboot.bin`이 있어야 합니다.
2. `적용하기.bat`을 더블클릭합니다. 원본 MD5를 확인하고 xdelta를 적용한 뒤 결과 MD5까지 검사합니다. 2분 정도 걸립니다.
3. `성공 948 / 전체 948, 문제 0`이 나오면 `한글패치\PCSG00341` 폴더에 결과가 만들어집니다. 원본 폴더는 바뀌지 않습니다.

**수동 적용(다른 OS)**: 파일마다 다음 명령을 실행합니다.

```bash
xdelta3 -d -s PCSG00341/eboot.bin patch/PCSG00341/eboot.bin.xdelta ko/PCSG00341/eboot.bin
```

**Python 스크립트**: 저장소의 `tools/apply_release.py`로도 같은 검사를 하며 적용할 수 있습니다.

```bash
python tools/apply_release.py --xdelta xdelta3 --source-dir PCSG00341 --patch-dir patch/PCSG00341 --output-dir ko/PCSG00341
```

xdelta는 호환성을 위해 압축·2차 압축 없이 만들었습니다. 그래서 적용이 빠릅니다.

### 3. 게임에 넣기

- **PS Vita 실기(rePatch, 권장)**: `한글패치\\PCSG00341` 폴더의 내용을 `ux0:rePatch/PCSG00341/`에 복사합니다. 원본 게임 폴더는 그대로 둡니다.
- **PS Vita 실기(직접 교체)**: `ux0:app/PCSG00341/`의 원본을 백업한 뒤 결과 파일로 덮어씁니다.
- **Vita3K**: 설치된 게임 폴더(`<Vita3K 데이터 폴더>/ux0/app/PCSG00341/`)에 결과 파일을 덮어씁니다.

948개를 모두 넣어야 합니다. 텍스트와 글꼴이 짝을 이루므로 일부만 넣으면 글자가 깨집니다. 일본판이므로 **○ 버튼이 결정, ✕ 버튼이 취소**입니다. 세이브 데이터 형식은 바꾸지 않았습니다.

### 번역 원칙

- 기계 번역 없이 일본어 원문과 문맥을 보며 직접 번역했습니다.
- 인물·작품명·게임 용어는 [용어집](docs/GLOSSARY.md)대로 통일했습니다. 각 작품의 국내 정식 발매판 표기를 우선했습니다.
- 대사창 폭에 맞춰 원문과 같은 줄 수를 유지했습니다. 캐릭터 말투를 살렸습니다. 시스템 문구는 「~합니다/~하시겠습니까?」로 통일했습니다.

### 번역하지 않은 것

- 음성(일본어)
- 성우·작가의 친필 사인
- 책 표지, 시리즈 로고, 電撃文庫 로고(캐릭터 선택 화면에는 작품명 한글 자막을 따로 넣었습니다)
- 노벨 갤러리 「로큐부!」 일부 6쪽: 아동을 성적으로 묘사하는 대목이라 원문 그대로 두었습니다.
- 온라인 기능(서비스 종료)

## 알려진 한계

- 모든 장면을 게임에서 직접 확인하지는 못했습니다. PC용 Vita3K에서 다음 화면을 확인했습니다.
  - 타이틀, 메인 메뉴, 캐릭터 선택
  - 노벨 갤러리
- 스토리 모드 대사창과 칭호 화면은 Vita3K 문제로 화면 확인을 못 했습니다. 문자열 단위로만 점검했습니다.
- 실기에서의 동작은 확인하지 못했습니다. 문제가 있으면 이슈로 알려 주세요.

## 저장소 구성

| 경로 | 내용 |
| --- | --- |
| `tools/build.py` | 원본 파일에서 한글판을 빌드(텍스트 인코딩, 글꼴 교체, 실행 파일 문자열 교체, 그림 글자 스크립트 실행) |
| `tools/` | 빌드·검증 도구(Python) |
| `text/ko/` | 텍스트 번역. 원문 대비 바뀐 구간만 담은 JSON(원문 없음) |
| `text/eboot.json` | 실행 파일 문자열 번역(원문 SHA-1 → 한국어) |
| `text/support.json` | 서포트 말풍선 번역(캐릭터·대사 번호 → 한국어) |
| `text/novel/` | 노벨 갤러리 번역(쪽마다 한 줄 = 한 문단) |
| `docs/` | 기술 설명, 재빌드 방법, 용어집, 글꼴 출처 |

`tools/`의 주요 도구는 다음과 같습니다.

- `extract.py`: 원본에서 번역 대상 텍스트를 UTF-8로 뽑기(`work/ja/`)
- `textdiff.py`: 원문 + `text/ko/` → 번역 텍스트(`work/ko/`)
- `fnt.py`: 게임 글꼴(`Font00.fnt`) 읽기·쓰기
- `gxt.py`: GXT 텍스처(DXT·스위즐) 읽기·쓰기
- `eboot.py`: 실행 파일 문자열 교체 후 FSELF 재구성
- `pac.py`: UKArc(`.pac`) 묶음 읽기·재구성, 말풍선 교체
- `img_*.py`: 화면별 그림 글자
- `emu.py`: 에뮬레이터 조작
- `apply_release.py`: 해시 검사 후 적용(Python용)
- `windows/적용하기.bat`, `windows/list.txt`: 릴리즈 ZIP에 들어가는 Windows용 적용 도구

권리 관련 내용은 [RIGHTS.md](RIGHTS.md)를 참고하세요.
