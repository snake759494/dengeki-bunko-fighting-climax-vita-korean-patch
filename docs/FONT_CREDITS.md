# 글꼴 출처

원본 일본어 글꼴에 맞춰 한글 글꼴을 골랐습니다. 게임 글꼴과 제목·라벨은 고딕 계열이고, 세로쓰기 소설 본문과 캐릭터 프로필은 명조 계열입니다. 아주 작은 그림 글자만 비트맵 글꼴(갈무리)을 썼습니다.

| 용도 | 한글 글꼴 |
| --- | --- |
| 게임 글꼴 `Font00.fnt`(대사·메뉴·설명 전체), 부팅 경고문 | 나눔스퀘어네오 Bd (`NanumSquareNeo-cBd.ttf`) |
| 그림 글자 제목·라벨·캐릭터 이름·작품명 자막 | 나눔스퀘어네오 Eb·Hv (`NanumSquareNeo-dEb.ttf`, `NanumSquareNeo-eHv.ttf`) |
| 캐릭터 선택 화면 세로 프로필·대사 | 서울한강체 EB (`SeoulHangangEB.ttf`) |
| 노벨 갤러리 본문(세로쓰기) | 서울한강체 M (`SeoulHangangM.ttf`) |
| 아주 작은 그림 글자(전투 HUD 얼굴 아이콘 이름 등) | 갈무리11 Bold (`Galmuri11-Bold.ttf`), 갈무리9 (`Galmuri9.ttf`) |
