# 기술 설명

## 게임 폴더 구조

PS Vita 일본판(PCSG00341)은 아카이브 없이 낱개 파일로 되어 있습니다. 바꾸는 파일은 다음과 같습니다.

| 경로 | 형식 | 내용 |
| --- | --- | --- |
| `System/str_jp/*.csv`, `*.ini` | Shift-JIS 텍스트 | 메뉴·시스템 문구, 칭호(`TitleList.csv`), 아이콘·플레이트 이름 |
| `System/BtlCharaTbl*.txt`, `bg/BgList.txt` | Shift-JIS 텍스트 | 캐릭터·스테이지 이름 |
| `BattleRes/talk/script/**` | Shift-JIS 스크립트 | 스토리 모드 대화 |
| `BattleRes/win_mes/script/**` | Shift-JIS 스크립트 | 승리 대사 |
| `grpdat/command/*.txt` | Shift-JIS 텍스트 | 기술표 |
| `grpdat/Special/Illustration/**`, `grpdat/Network/**` | Shift-JIS 텍스트 | 갤러리·네트워크 문구 |
| `grpdat/Font/Font00.fnt`, `Font_NNNN.gxt.gz` | 글꼴 표 + 텍스처 | 게임 글꼴 |
| `grpdat/**/*.gxt.gz` | gzip으로 감싼 GXT 텍스처 | 그림 글자 |
| `eboot.bin` | SELF | 실행 파일 안 버튼 안내 문구 |

## 텍스트와 한글 인코딩

게임은 텍스트를 Shift-JIS(cp932) 2바이트 코드로 읽어 `Font00.fnt` 표에서 글리프를 찾습니다. 한글을 넣을 새 코드는 없습니다. 그래서 번역에 쓰이지 않는 한자 칸을 한글 칸으로 빌려 씁니다.

- 대상 칸: 2바이트 영역 `0x989F`~`0xEAA4` 중 하위 바이트가 제어 문자와 겹치지 않는 칸
- 조건: 글리프 상자가 21×21 이상인 칸
- 번역에 쓰인 한글 1,025자를 코드 순서대로 배정합니다.
- 텍스트 파일은 한글을 배정된 코드로, 나머지는 cp932로 씁니다.
- 바꾼 칸의 글리프는 글꼴 텍스처(DXT5 알파, Morton 순서 블록)에 나눔스퀘어네오 Bd 20px로 다시 그립니다. 바뀐 블록만 다시 인코딩합니다.
- 글꼴 표 항목 형식(22바이트): 코드(u32), 텍스처 번호, 기준 오프셋, 너비·높이, 텍스처 좌표(i16×9)

번역 텍스트는 원문 파일과 줄 수·제어 코드가 같아야 합니다. `\n` `\k` 같은 제어 코드, `@236A@` 커맨드 표기, `%d` 같은 치환자는 그대로 둡니다.

## 실행 파일 문자열

`eboot.bin`은 SELF입니다. 빌드에는 사용자가 직접 복호화한 ELF(`work/orig/eboot.elf`)가 필요합니다.
- `tools/eboot.py`가 ELF 안에서 NUL로 끝나는 문자열마다 SHA-1을 계산합니다.
- `text/eboot.json`의 원문 해시와 맞으면 한국어로 바꿉니다.
- 한국어는 원문 바이트 길이 안에 넣고, 남는 칸은 0으로 채웁니다.
- 원본 SELF 헤더를 그대로 쓰고 세그먼트 오프셋·크기만 고쳐 FSELF로 다시 감쌉니다.

## GXT 텍스처

`.gxt.gz`는 gzip으로 감싼 PS Vita GXT입니다.
- 형식: DXT1(`0x85000000`)·DXT5, 스위즐 배치
- 도구: `tools/gxt.py`
  - 읽기: 헤더의 텍스처 표를 읽고 블록을 풉니다.
  - 쓰기: 바뀐 4×4 블록만 다시 인코딩해 같은 위치에 덮어씁니다. 크기와 헤더는 원본과 같습니다.

화면별 그림 글자는 `tools/img_*.py`가 그립니다. 원본 글자 영역을 지우고, 원본 색·테두리·기울기에 맞춰 한글을 그립니다.

## 노벨 갤러리

`grpdat/Special/Novel/gallery_novel_vita/gal_bookNN/`에 책 19권이 있습니다. 각 쪽은 1808×1024 DXT1 텍스처이고, 일본어 본문이 세로쓰기로 그림에 박혀 있습니다.

1. 종이 배경: 모든 본문 쪽의 화소별 중앙값으로 공통 종이 배경(`work/novel/bg.png`)을 만듭니다.
2. 책별 배경: 쪽마다 공통 배경에 가장 가까운 값을 고릅니다. 시리즈 로고 워터마크는 남고 글자는 지워집니다.
3. 본문: `text/novel/novelBB_PPP.txt`(한 줄 = 한 문단)를 서울한강체 M 21px로 세로쓰기합니다.
   - 문장부호(「」…— 등)는 90도 돌리고, 마침표·쉼표는 칸 오른쪽 위에 둡니다.
   - 줄머리 금칙 문자는 한 칸까지 줄 끝에 매답니다.
   - 본문이 넘치면 글자 크기를 최대 0.62배까지 줄입니다.
4. 쪽수 표시와 표지(`_000`)는 원본 그대로 둡니다. 마지막 쪽은 오른쪽 안내문 영역만 바꿉니다.
5. `[미번역]` 표시가 있는 쪽은 원본 그대로 둡니다.
